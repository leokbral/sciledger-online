# SciLedger

SciLedger is a web application for submitting, peer reviewing, and publishing scientific work. It also organizes journals, conferences, and working groups through hubs.

> **Project status:** Under development. Features and workflows may change.

## Technology

- **Application:** SvelteKit, Svelte, and TypeScript
- **Interface:** Tailwind CSS and Skeleton UI
- **Data:** MongoDB, accessed through Mongoose and the official driver
- **Integrations:** ORCID, email services, and document conversion

## Requirements

- Node.js and npm versions compatible with the project dependencies
- An accessible MongoDB instance
- Credentials for the integrations used in your environment

## Local setup

1. Install dependencies:

   ```bash
   npm ci
   ```

   Installation also runs the `postinstall` script, which prepares Chromium for Playwright.

2. Copy `.env.example` to `.env` and update the values for your environment:

   ```bash
   cp .env.example .env
   ```

   In PowerShell, use `Copy-Item .env.example .env`. Do not commit `.env`.

3. Set `MONGO_URL` to the database used by the application. Some scripts also read `MONGODB_URI`; keep both variables aligned when running those scripts. The example file documents the ORCID, email, application URL, and DOCX conversion settings.

4. Start the development server:

   ```bash
   npx vite dev
   ```

   The `npm run dev` script starts an SSH tunnel using the `mongovm` alias and Windows commands. Use it only if that access is configured in your environment.

Vite uses port `5173`, as configured in `vite.config.ts`.

## Commands

| Command                    | Purpose                                         |
| -------------------------- | ----------------------------------------------- |
| `npm run check`            | Sync SvelteKit and check types and components.  |
| `npm run test:unit`        | Run unit tests with Vitest.                     |
| `npm run test:integration` | Run integration tests with Playwright.          |
| `npm test`                 | Run integration tests, followed by unit tests.  |
| `npm run lint`             | Check formatting and ESLint rules.              |
| `npm run build`            | Build the application for production.           |
| `npm run preview`          | Preview the production build locally.           |
| `npm start`                | Start the server generated by the Node adapter. |

The production build is written to `build/` by `@sveltejs/adapter-node`. Configure environment variables and MongoDB access before starting the server.

## Project structure

| Path                  | Contents                                  |
| --------------------- | ----------------------------------------- |
| `src/routes/`         | SvelteKit pages, layouts, and endpoints.  |
| `src/lib/components/` | Reusable interface components.            |
| `src/lib/db/`         | MongoDB connections, models, and schemas. |
| `src/lib/services/`   | Application services and integrations.    |
| `scripts/`            | Migration and administration scripts.     |
| `tests/`              | Tests and supporting resources.           |
